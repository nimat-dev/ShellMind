## Summary

De-risks the fundamental thesis of ShellMind in Phase 00 (Feature F000):
1. **Subscription-based Headless Claude Code**: Proved that `claude -p "<prompt>" --output-format stream-json --verbose` executes successfully using the local logged-in Claude Code subscription with **zero** `ANTHROPIC_API_KEY` in environment.
2. **Mandatory Flags Discovered**: Claude Code CLI requires `--verbose` when `--output-format=stream-json` is used with `-p`.
3. **Telemetry & Rate Limit Window Monitoring**: Discovered and verified parsing of `rate_limit_event` payloads (utilization and `resetsAt` for 5h/7d windows).
4. **Programmatic Permission Interception**: Successfully routed tool permission prompts to a headless MCP server using `--permission-prompt-tool mcp__<server>__<tool>`. Demonstrated programmatic allow (executes command and writes file) and programmatic deny (blocks command with custom message and omits file creation).
5. **JSONL Stream Parser**: Implemented typed stream parser converting raw JSONL streams into discrete typed events (`assistant_text`, `tool_use`, `tool_result`, `rate_limit`, `done`).
6. **Architecture Record**: Documented findings and chosen mechanisms in `ADR-0001` and `DECISIONS.md`.
