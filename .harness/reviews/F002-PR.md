## Summary

Implements **F002 — Agent daemon + tailnet transport + device-token auth** in Phase 01:
1. **Wire Protocol Handshake Messages (`@shellmind/protocol`)**:
   - Added `hello`, `hello.ack`, `hello.reject` schemas and constructor helpers in `packages/protocol/src/messages/hello.ts`.
   - Registered handshake message types in `MessageRegistry` and codec.
2. **Pure Core Interfaces & Daemon (`packages/agent/src/core`)**:
   - `Transport`, `TransportConnection`, and `TransportListener` interfaces defined in `core/transport.ts` (strictly side-effect and Node-free).
   - `IDeviceRegistry` and `PairedDevice` interfaces defined in `core/device.ts`.
   - `AgentDaemon` implemented in `core/daemon.ts`:
     - Enforces device-token authentication before accepting messages.
     - Dispatches messages via extensible `MessageHandler` registry conforming to `MODULES.md §1`.
     - Maps authenticated sessions to client connections.
     - Rejects unauthenticated/premature frames, bad tokens, and revoked devices.
3. **Concrete Transport & Storage Adapters (`packages/agent/src/adapters`)**:
   - `TailnetTransportServer` in `adapters/transport/tailnet.ts`:
     - Detects Tailscale CGNAT IPs (`100.64.0.0/10`) and interfaces.
     - Strictly refuses to bind to `0.0.0.0`.
     - Backed by WebSocket server (`ws`).
   - `FileDeviceRegistry` in `adapters/storage/device-registry.ts`:
     - Enforces SHA-256 token hashing; raw token literals are never persisted to disk or logged.
     - Restricts file permissions strictly to `0600` (user read/write only).
     - Provides device creation, lookup, and revocation.
4. **ShellMind CLI (`packages/agent/src/cli.ts`)**:
   - Commands: `pair`, `devices`, `revoke`, `dev`, `status`.
   - `dev` refuses to start when no Tailscale interface is found, giving actionable error messages.
5. **Architectural Guard & Verification**:
   - Verified pure core invariant: zero Node built-in or adapter imports in `packages/agent/src/core` and `packages/protocol`.
   - `check-architecture` passed with 0 violations across 24 modules.
   - 25/25 unit and integration tests passing (`agent.test.ts` drives real WebSocket sockets across 8 happy and edge cases).
